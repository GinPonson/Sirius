# Sirius 人工验证清单（115 远程流程）

按 `docs/progress.md` 各行记录的验证步骤汇总而成。请在登录 115 后逐项执行并回填「结果」列。
前置条件：`npm run tauri dev`（或安装打包后的 .app）→ 启动应用 → 在登录首屏扫码完成 115 授权。

## 1. 批量选择与批量操作

| 步骤 | 预期 | 结果 |
| --- | --- | --- |
| 网盘文件 → 勾选多个文件（含文件夹） | 出现批量操作栏，显示「已选 N 项」 | |
| 批量移动 → 在对话框逐级进入目标文件夹 → 移动到这里 | 提示已移动 N 项；列表刷新，文件从当前目录消失 | |

| 勾选后在当前筛选下全选/取消全选 | 全选只作用于当前可见项；再切换筛选后选择被清空，不会带入被筛掉的项 | |

## 9. 固定本机签名与分发公证

个人安装使用长期保留的 `Sirius Local Development` 自签代码签名证书。
私钥保存在 Sirius 专用签名钥匙串；公开身份指纹保存在
`~/Library/Application Support/com.sirius.desktop/signing/identity.json`。
同目录的专用解锁材料仅供本机构建，目录权限为 0700、文件权限为 0600，不进入仓库或应用包。
签名时自动解锁专用库，临时加入构建搜索列表，结束后移除本次新增的搜索项并锁回。
完成首次证书信任后，后续构建签名不需要个人钥匙串或 Mac 登录密码。
应用标识固定为 `com.sirius.desktop`。重装、重构建时复用原证书，不重新生成签名身份。
**固定自签证书不能保证不同构建沿用登录凭据授权。** 2026-10-18 实测发现，
macOS 为此自签应用使用 `cdhash:` 凭据访问分区，重新构建后仍会请求授权。
用户已选择保留当前本机自签方案，暂不配置 Apple 签发的签名身份。

| 步骤 | 预期 | 结果 |
| --- | --- | --- |
| 首次运行 `python3 scripts/setup-local-signing.py`，人工完成必要的系统验证 | 创建专用签名库及证书，配置签名工具权限、当前用户代码签名信任，并通过真实私钥签名验证；不授予 SSL 信任 | 2026-10-18 通过；用户已完成必要信任确认 |
| 再次运行设置脚本 | 复用相同证书指纹；证书丢失或身份不一致时明确失败 | 通过；重复设置与签名探针复用同一证书，无个人钥匙串签名授权 |
| `npm run build:local` | 构建后自动签名；应用与全部 dylib 使用固定证书，深度严格签名校验通过，DR 绑定应用标识与证书 | 通过；最终 0.1.1 已安装，50 个 Mach-O 的依赖与 LC_RPATH 无 Homebrew 绝对路径 |
| 安装并首次启动，完成旧凭据的一次必要授权 | 成功读取登录状态；首次读取后普通账号查询和网络请求不反复弹窗 | 同一已授权构建通过；不能据此推断下一次构建免授权 |
| 退出并重新启动安装版 | 登录状态正常，钥匙串已解锁时不再请求同一凭据授权 | 已授权的 0.1.0 和首个 0.1.1 构建通过；0.1.1 重开约 1 秒进入主界面 |
| 再构建不同二进制、用同一证书签名并覆盖安装 | 两版二进制哈希不同、DR 相同；启动后沿用凭据授权 | **未通过**；用户确认每次换构建仍出现 Sirius 登录凭据授权。相同 DR 不能消除独立的 cdhash 分区检查 |
| 打开设置和 AI 配置，重复进入文件页 | 界面响应正常，缓存的凭据不重复触发系统读取 | 已授权的 0.1.1 构建通过；AI 配置为空，未调用真实模型 |
| 读取钥匙串被拒绝 | 显示真实错误和重新打开应用的指引，不自动重试堆积系统授权 | 成功、空值、失败缓存与并发读取均由离线测试覆盖；本轮未主动拒绝真实凭据权限 |
| 分发时使用 Developer ID 证书和公证凭据运行 `./scripts/sign-and-notarize.sh` | Hardened Runtime 签名、公证及装订成功；本机自签模式不执行公证 | 仅分发时执行 |

覆盖安装结论已根据用户反馈修正：仅观察应用页面不能判断系统是否出现了授权弹窗。
对精确匹配的 Sirius 115 条目只读查询引用及 ACL 元数据，未请求密码数据，确认了独立的
`ACLAuthorizationPartitionID`，其中保存的两条 `cdhash:` 与两个 0.1.1 构建的 CDHash 一致。
最终安装包的 `TeamIdentifier` 为 `not set`。Apple 签发且被系统识别的开发签名可采用
`teamid:` 分区；本机目前没有该签名身份，跨版本免弹窗验收保持未通过。
参考：[Apple 关于独立 ACL 与 partition 条件的说明](https://developer.apple.com/forums/thread/845980)、
[Apple Security 分区实现](https://github.com/apple-oss-distributions/Security/blob/main/securityd/src/clientid.cpp#L187-L287)。
