# Sirius 人工验证清单（115 远程流程）

按 `docs/progress.md` 各行记录的验证步骤汇总而成。请在登录 115 后逐项执行并回填「结果」列。
前置条件：`npm run tauri dev`（或安装打包后的 .app）→ 启动应用 → 在登录首屏扫码完成 115 授权。

## 1. 批量选择与批量操作

| 步骤 | 预期 | 结果 |
| --- | --- | --- |
| 网盘文件 → 勾选多个文件（含文件夹） | 出现批量操作栏，显示「已选 N 项」 | |
| 批量移动 → 在对话框逐级进入目标文件夹 → 移动到这里 | 提示已移动 N 项；列表刷新，文件从当前目录消失 | |
| 批量复制到另一目录 | 列表刷新后出现副本 | |
| 批量删除 → 确认 | 提示移入回收站；在 115 官网回收站中可看到并还原 | |

## 2. 上传与断点恢复

| 步骤 | 预期 | 结果 |
| --- | --- | --- |
| 工具栏「上传」→ 选择 1 个 ≤20MiB 文件 | 通知上传成功，文件出现在当前目录 | |
| 选择 1 个 >20MiB 文件（≤任意大小） | multipart 分片上传成功（64MiB 上限已移除） | |
| 上传中途强制退出应用 → 重启 → 相册恢复横幅/上传会话 | 「恢复」按钮可用，点击后续传完成 | |
| 上传同名冲突文件 | Rust 策略拒绝并显式报错 | |

## 3. 下载与断点续传

| 步骤 | 预期 | 结果 |
| --- | --- | --- |
| 文件菜单「下载」→ 选择保存目录 | 通知已下载，文件落盘且大小正确 | |
| 大文件下载中断（断网/强退）→ 重新执行同一文件的下载 | 从 `.sirius-part` 断点续传，通知含「续传完成」 | |
| 下载到已存在同名文件的位置 | 显式报错提示目标已存在 | |

## 4. AI 整理工作流

| 步骤 | 预期 | 结果 |
| --- | --- | --- |
| AI 整理页 → 填写服务商地址/模型/API 密钥 → 保存 | 提示「已保存」；密钥状态变为「已保存在钥匙串」 | |
| 选择目录 → 生成整理计划 | 计划预览表出现（保持/重命名/移动/删除 + 理由），明确标注未执行 | |
| 勾选若干项（删除项默认不勾选）→ 执行所选项 → 确认 | 执行报告：已执行/跳过/失败计数与逐项明细 | |
| 删除一项 → 在 115 回收站还原 | 文件恢复 | |
| 移动到不存在的目标文件夹 | 自动创建目标文件夹并完成移动 | |

## 5. 漫画模式

| 步骤 | 预期 | 结果 |
| --- | --- | --- |
| 识别含 cbz/zip 的目录 | 按系列分组的书脊卡片 | |
| cbz 卷「阅读」 | 阅读器打开并显示页图（首次有下载等待） | |
| 翻页数页 → 关闭 → 重新打开同一卷 | 从上次页码续读 | |
| 再次进入漫画页 | 书架来自本机索引，卡片显示封面缩略图 | |

## 6. 相册模式

| 步骤 | 预期 | 结果 |
| --- | --- | --- |
| 识别含图片的目录 / 批量索引根目录 | 时间线按月份分组（从新到旧），行内缩略图 | |
| 切换「专辑」标签 | 每个已索引目录一张卡片（封面 + 照片数） | |
| 点选照片行 | 全屏预览：缩略图先显示，原图直链加载后切换 | |
| 预览中左右键翻张、Esc 关闭 | 正常 | |
| 选中专辑 → 重命名 | 115 目录名与专辑名同步更新 | |
| 选中专辑 → 移入回收站 → 115 官网还原 | 目录消失后可还原 | |
| 选中专辑 → 仅移除本机索引 | 时间线移除，115 文件不受影响 | |

## 8. 长播放稳定性

| 步骤 | 预期 | 结果 |
| --- | --- | --- |
| 连续播放 115 视频 ≥1 小时 | 不崩溃、无内存异常增长 | |
| （可选，难构造）播放中等待 HLS/直链过期 | 播放自动恢复到接近中断位置；恢复失败时出现明确错误横幅 | |
| 批量操作期间观察请求节奏 | 控制面请求间隔约 1 秒（匀速，无突发） | |
